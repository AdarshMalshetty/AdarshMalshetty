## About Me

I'm an **Infrastructure & DevOps Engineer II** with **4+ years of experience** building and operating cloud and on-premises infrastructure across **Microsoft Azure**, **Google Cloud Platform**, and self-hosted virtualised environments.

My work spans end-to-end infrastructure ownership — provisioning Azure IaaS with Terraform, configuring systems with Ansible, running multi-tenant Kubernetes platforms at 99%+ uptime, and managing on-prem virtualisation with **Hyper-V** and Linux. I've handled everything from CI/CD automation to specialist work like provisioning **NVIDIA GPU-capable Azure VMs** (NCv3/NCasT4) for an AI-based retail loss prevention platform.

I understand systems from the network and OS layer up through containers, orchestration, and automation — not just the tooling.
